Chroma is a vector database: built to store and search vectors (numerical 
representations of things like text, images, or audio).



https://medium.com/@tahirbalarabe2/how-to-use-chroma-db-for-similarity-search-188e490badac

Getting start with Chroma DB:
- create a client (the interface to the database)
- create a collection (like a table, but for vectors)
- add database
- query it (ask for the most similar items)
